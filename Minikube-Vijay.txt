we need to install docker : yum install docker -y && systemctl start docker

1) installation of minikube (https://minikube.sigs.k8s.io/docs/start/?arch=%2Flinux%2Fx86-64%2Fstable%2Fbinary+download) 

.curl -LO https://github.com/kubernetes/minikube/releases/latest/download/minikube-linux-amd64
.sudo install minikube-linux-amd64 /usr/local/bin/minikube && rm minikube-linux-amd64


2) installation of kubectl (https://kubernetes.io/docs/tasks/tools/install-kubectl-linux/#install-kubectl-binary-with-curl-on-linux)

.curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"

3) give permission to kubectl : chmod +x kubectl
4) move to default path : mv kubectl /usr/local/bin
5) check version : kubectl version
6) minikube start --driver=docker --force
7)minikube status
8)kubectl api-resources
